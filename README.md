# Cuervo Encounter Engine

Motor ligero para administrar encuentros de combate de **Las Cenizas de la Marea**.

## v0.1
- Carga manual de personaje jugador, aliados y enemigos.
- Iniciativa y orden de turnos.
- Decisiones manuales para el personaje jugador.
- Resolución automática básica de ataques para aliados y enemigos.
- Seguimiento de PV, CA y estado de los participantes.
- Registro detallado, cierre del encuentro y exportación del resumen en texto.

## Uso
Abrí `index.html` en un navegador moderno. Para publicar con GitHub Pages, habilitá Pages desde **Settings → Pages** y seleccioná **Deploy from a branch → main → /(root)**.

## Datos y privacidad
Los encuentros se mantienen en memoria durante la sesión. Esta versión no envía fichas ni registros a un servidor. No incluyas información privada de campaña en este repositorio público.

## Límites de la versión preliminar
La automatización de PNJ usa ataques básicos configurables. Las acciones especiales, condiciones complejas, movimiento táctico, salvaciones y habilidades requieren adjudicación manual. El motor es un asistente de gestión, no un sustituto de las reglas ni del criterio del director de juego.
